# Toddle-Cation

A simple check-in for toddlers to pick a feeling and a color that matches how they feel.

Serve the app over HTTPS or localhost to use location and save check-ins. To install it on a device, publish all app files (including the `icons` folder) together on an HTTPS web host. Installation and offline support also require HTTPS, or localhost for development. No account is required.

After a feeling and color are selected, an adult can allow the browser to access the device's location. Location is required to save; if permission is denied or location is unavailable, the check-in is not saved. Each saved check-in contains the feeling, color, local date and time, UTC timestamp, UTC-minus-local offset in minutes, coordinates, and reported location accuracy. These records are stored in a local browser database on that device and are not sent by the app to a server. Select **Saved check-ins** to review, download as CSV, or delete them. A downloaded CSV contains sensitive location data: keep it private and delete downloaded copies separately. Browser storage can be cleared or unavailable, and records do not sync between browsers or devices. Location may use GPS, Wi-Fi, or other device services; offline saving works only when the device can determine its location without a connection.

Use **Install** to open the setup dialog. An adult can choose **Allow location** there before continuing to the browser's installation prompt or instructions. The browser asks for permission, and the device's location services may need to be enabled in its settings; the app cannot turn them on automatically. This setup check does not save a location. On iPhone and iPad, use the browser's Share menu and choose **Add to Home Screen**; older iOS versions require Safari. On a Mac, Safari offers **File > Add to Dock**. Chrome and Edge also offer installation from their menus or address bars. Browser and operating-system versions may vary. Open the app online once before using it offline; device-provided speech voices and downloaded fonts may not be available offline. Installed apps may have separate location permissions from the browser.

The app uses the device's built-in speech voices, preferring an enhanced, natural-sounding English female voice when available, with a gentle speaking pace. Voices vary by device, so the sound and voice cannot be guaranteed; some voices may require a download or internet connection. Some browsers, including Safari on iOS, require a tap before speech can play: use **Hear the question** on the first screen. The color question is spoken after selecting a feeling. The sound button can repeat either question.
