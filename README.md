# Toddle-Cation

A gentle, two-screen communication tool for children to share how they feel and why.

Open `index.html` in a modern browser, or serve this directory as a static website. No account, installation, or internet connection is needed after the files are available on the device.

Choose a color, then one or more pictures (or the question mark). Tap **Save my report** to download a PDF to the device. The browser controls where the file is saved; on iPhone or iPad, use the browser's download or Share/Save to Files controls if prompted. Reports are not sent to a server. They remain wherever the device saves downloads until you delete them.

Tap **Turn voice on** to hear the questions. This interaction is required by some browsers, including Safari on iOS. The app prefers an available English female-sounding system voice, but voice availability and characteristics depend on the device. The questions remain visible if speech is unavailable. Use the speaker button to repeat a question, or turn the voice off at any time.
