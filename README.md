# Toddle-Cation

A simple check-in for toddlers to express their feelings through colors and pictures.

Open `index.html` in a browser to use the app. To install it on a device, publish all app files (including the `icons` folder) together on an HTTPS web host. Installation and offline support require HTTPS, or localhost for development. No account is required, and selections are not saved or sent anywhere.

Use the **Install** button for the browser's installation prompt or instructions. On iPhone and iPad, use the browser's Share menu and choose **Add to Home Screen**; older iOS versions require Safari. On a Mac, Safari offers **File > Add to Dock**. Chrome and Edge also offer installation from their menus or address bars. Browser and operating-system versions may vary. Open the app online once before using it offline; device-provided speech voices and downloaded fonts may not be available offline.

The app uses the device's built-in speech voices and prefers an available English female voice. Available voices vary by device, so a female voice cannot be guaranteed. Some browsers, including Safari on iOS, require a tap before speech can play: use **Hear the question** on the first screen. The second question is spoken after selecting a color. The sound button can repeat either question.
