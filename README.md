# Toddle-Cation

A simple check-in for toddlers to pick a feeling and a color that matches how they feel.

Serve the app over HTTPS or localhost to use location and save check-ins. To install it on a device, publish all app files (including the `icons` folder) together on an HTTPS web host. Installation and offline support also require HTTPS, or localhost for development. No account is required.

After a feeling and color are selected, the device owner can optionally add notes, then an adult can allow the browser to access the device's location. On the notes page, press Enter to continue to the save confirmation or Shift+Enter to add a new line. Location is required to save; if permission is denied or location is unavailable, the check-in is not saved. Each saved check-in contains the feeling, color, notes, local date and time, UTC timestamp, UTC-minus-local offset in minutes, coordinates, reported location accuracy, and the browser-provided device/browser description (not a unique device ID). Older check-ins have no device description or notes. Records are stored in a local browser database and are not sent by the app to a server. Browser storage can be cleared or unavailable, and records do not sync between browsers or devices. Location may use GPS, Wi-Fi, or other device services; offline saving works only when the device can determine its location without a connection.

After saving, the final popup offers **Save and Download Check-In**, which downloads the current check-in as `check-in.csv` with only local date, local time, mood, color, and notes, or **Close**, which keeps the saved check-in on the device without downloading it. Check-ins waiting to be downloaded remain queued across app updates and are listed under **Saved check-ins**. After a download starts or a folder export completes, a **You are appreciated** popup lets you clear the downloaded record(s) from this device or save them for later. Clearing affects only those downloaded records; saving for later keeps them in the local database. Select **Saved check-ins** to review, export, or delete the records. **Export checkins.csv** asks you to choose a parent folder in browsers that support folder access; it creates a `checkins` folder there and creates or replaces `checkins.csv` with all current records, including notes, location, and device data. In other browsers, the file downloads as `checkins.csv` to the browser's download location; create a `checkins` folder and move it there if desired. Exports are snapshots and are not updated automatically. Exports may contain sensitive information: keep them private and delete exported copies separately.

The installed app offers a demo on its first launch, when the browser can detect that it is installed. You can also select **Help** at the top of the page and **Start demo** at any time for a step-by-step walkthrough that does not save a check-in or request location. Choose **Print or save as PDF** in Help or the demo to print all the walkthrough steps or select **Save as PDF** in the device's print options, where available. The demo leaves an unfinished check-in unchanged and is available offline after the app has been cached. Clearing browser storage can cause the first-launch offer to appear again.

An install popup appears once per browser-tab session, or select **Install app** in the header at any time. Supported browsers show their install prompt immediately; otherwise the app shows instructions for your device. On iPhone and iPad, tap Share and choose **Add to Home Screen**; if that option is missing, use Safari. On a Mac, Safari offers **File > Add to Dock**. Chrome and Edge also offer installation from their menus or address bars. The browser and operating system control installation, and availability varies by device. After accepting the install prompt, or in the instructions dialog, an adult can optionally choose **Allow location**. The browser asks for permission, and the device's location services may need to be enabled in its settings; the app cannot turn them on automatically. This setup check does not save a location. Installed apps may have separate location permissions and storage from the browser; existing check-ins might not appear in the installed app. Open the app online once before using it offline; device-provided speech voices and downloaded fonts may not be available offline.

The app uses the device's built-in speech voices, preferring an enhanced, natural-sounding English female voice when available, with a gentle speaking pace. Voices vary by device, so the sound and voice cannot be guaranteed; some voices may require a download or internet connection. Some browsers, including Safari on iOS, require a tap before speech can play: use **Hear the question** on the first screen. The color question is spoken after selecting a feeling. The sound button can repeat either question.

When a newer version is ready, an **Update app** notice appears. Finish any check-in first: updating reloads the app, but keeps saved check-ins in the same browser or installed app storage. Updates require an online connection and browser support for service workers. Browsers cannot reliably detect an installation made in a separate browser or app context, so the notice is based on an available app update rather than whether another installation exists.
